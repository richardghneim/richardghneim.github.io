## Om Richard Ghneim

Richard Ghneim är grundare och VD för **CityFast Bygg och förvaltning Sverige AB** — ett familjeägt fastighetsbolag grundat 2005, verksamt i Stockholm med fokus på kommersiella fastigheter och bostäder.
